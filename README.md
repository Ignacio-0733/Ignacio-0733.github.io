# Ignacio Pérez Fernández — IT Portfolio

Personal portfolio focused on IT systems, networking, automation, programming and the long-term goal of working in motorsport technology.

## Contents
- `index.html` — page structure and portfolio content
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and dynamic footer year

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a public repository named **`Ignacio-0733.github.io`** in your GitHub account.
2. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will be `https://Ignacio-0733.github.io/`.

## Before publishing
- Check the experience dates and descriptions.
- Add direct links to individual repositories if desired.
- Confirm that the course names match the certificates you hold.
- Consider adding a professional email address if you want recruiters to contact you directly.
